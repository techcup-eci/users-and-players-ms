# Objetivo:

Gestionamos de forma autonoma y segura la información de los usuarios y jugadores de la plataforma TECHCUP FÚTBOL, permitiendo el registro de perfiles deportivos, la búsqueda de jugadores disponibles y el flujo de solicitudes e invitaciones para la conformación de equipos, garantizando integridad de datos, trazabilidad de acciones y comunicación eficiente con los demás microservicios del sistema.
